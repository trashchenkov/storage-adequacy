# Расчёты для совместных ограничений ENS и LOLH

Комплект к рукописи **Additional firm capacity for joint energy-not-served and loss-of-load-hours limits in storage systems**, автор — Sergei Trashchenkov.

Репозиторий: [https://github.com/trashchenkov/storage-adequacy](https://github.com/trashchenkov/storage-adequacy).

Архив версии **v1.0.0** в Zenodo: [10.5281/zenodo.23315908](https://doi.org/10.5281/zenodo.23315908). Эта ссылка указывает на конкретную версию расчётного комплекта, использованную в рукописи.

Здесь находятся код, исходные параметры, сохранённые результаты и построение двух численных графиков статьи. Полная документация: [README.md](README.md). Сборка рукописи в этот комплект не входит.

## Запуск

Из этой папки, с Python 3.12:

```bash
python3 verify_repository.py
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python reproduce.py
```

На Windows команда активации — `.venv\Scripts\activate`. Решатель HiGHS входит в SciPy.

Результаты появятся в `generated/`: сводка `summary.json`, полные решения, точные рациональные проверки и папка `figures/` с графиками PNG/SVG и данными CSV. Повторный запуск разрешён; эталонные файлы из `results/reference/` не меняются. Проверка целостности работает без научных библиотек. Результаты проверки комплекта записаны в [VALIDATION.md](VALIDATION.md).

## Что проверяется

- 15 заранее заданных наборов параметров: 45 исходных задач, 15 вспомогательных задач, 15 задач расчёта границы B и допустимость обратного преобразования режимов.
- Независимая реализация четырёхчасового примера и проверки расчёта границы.
- Точные рациональные сертификаты четырёхчасового примера и пяти членов предельной последовательности.
- 360 проверок режимов общего аналитического семейства и пример увеличения потока.
- Построение численных рисунков 4 и 5; значения Γ, B и Δ из таблиц 2 и 3.

Сравниваются оптимальные значения и выполнение физических ограничений. Сами оптимальные режимы могут различаться при вырожденности задачи. Программы сохраняют невязки, статусы и доступные оценки оптимальности решателя. Численные проверки примеров дополняют доказательства в рукописи.

## Обозначения и ограничения модели

`x` — генерация минус потребление до учёта накопителей и дополнительного источника. `E`, `Pc`, `Pd`, `eta` — ёмкость, мощности заряда и разряда, КПД. Шаг — один час; мощности заданы в МВт, энергия — в МВт·ч. Начальные запасы энергии выбираются свободно и восстанавливаются к концу периода. Заряд разрешён из внешнего избытка, переток между накопителями исключён.

`Ebar` задаёт предел недоотпуска электроэнергии ENS, `Hbar` — предел числа часов дефицита LOLH. `Gamma` — разность совместного минимума мощности источника и большего из раздельных минимумов. `B` и `Delta` — достаточные верхние границы этой добавки. Система описывается единым энергетическим балансом; сетевые ограничения в модель не входят.
